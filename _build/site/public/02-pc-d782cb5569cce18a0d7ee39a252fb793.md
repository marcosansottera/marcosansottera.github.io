# Microprocessore

Il microprocessore è un circuito elettronico dedicato all'elaborazione
di istruzioni, costituito da uno o più circuiti integrati di
dimensioni molto ridotte.

La tecnologia a microprocessore è attualmente quella più utilizzata
per la realizzazione della CPU e della GPU (montate direttamente su
una scheda madre) ed è impiegata dalla quasi totalità dei moderni
computer, con la caratteristica di utilizzare, per tutte le sue
elaborazioni, un insieme di istruzioni fondamentali di base.
